[English](#english) · [简体中文](#简体中文)

## English

**Understand checkout. Build your next theme.**

ShopZend builds focused Shopify products for merchants and theme developers.

### Checkout Monitor — for merchants

Brings checkout extension errors, messages shown to buyers, and checkout timelines into your Shopify admin.

[Product page](https://shopzend.com/products/checkout-monitor) · [Shopify App Store](https://apps.shopify.com/shopzend-store-monitor)

### Vite for Shopify — for theme developers

Develop with Vite HMR. Build, verify, and deliver a standard Shopify theme through one Theme Run workflow.

```bash
pnpm add -D vite-plugin-shopify-theme
```

[Product page](https://shopzend.com/products/vite-plugin-shopify-theme) · [Documentation](https://shopzend.com/docs/vite-plugin-shopify-theme) · [Source](https://github.com/shopzend/vite-plugin-shopify-theme) · [npm](https://www.npmjs.com/package/vite-plugin-shopify-theme)

## 简体中文

**看清结账问题，专注主题开发。**

ShopZend 为商家和主题开发者打造专注实用的 Shopify 产品。

### Checkout Monitor（面向商家）

在 Shopify 后台集中展示结账扩展错误、买家看到的提示与结账时间线。

[产品页](https://shopzend.com/zh-cn/products/checkout-monitor) · [Shopify App Store](https://apps.shopify.com/shopzend-store-monitor)

### Vite for Shopify（面向主题开发者）

用 Vite HMR 获得即时开发反馈，通过一套 Theme Run 工作流完成标准 Shopify 主题的构建、校验与交付。

```bash
pnpm add -D vite-plugin-shopify-theme
```

[产品页](https://shopzend.com/zh-cn/products/vite-plugin-shopify-theme) · [文档](https://shopzend.com/zh-cn/docs/vite-plugin-shopify-theme) · [源码](https://github.com/shopzend/vite-plugin-shopify-theme) · [npm](https://www.npmjs.com/package/vite-plugin-shopify-theme)
